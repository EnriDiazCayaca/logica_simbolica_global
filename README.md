## 🏆 Rúbrica de Evaluación

- **🧠 Lógica Matemática (40%):** El algoritmo resuelve el problema sin errores.
- **🎨 UI / UX (30%):** Diseño limpio y funcional con Tailwind CSS.
- **🤝 Git (30%):** Commits limpios, PRs a tiempo (Viernes 4-6 PM).

> [!WARNING]
> **Este proyecto evalúa SOLO el producto (código/UI).** Las preguntas teóricas del profesor son una evaluación completamente separada e independiente.

---

## 👩‍💻 Flujo de Trabajo

**Roles en cada equipo:**
- **Sublíder:** Consolida el trabajo del equipo y hace el Pull Request semanal.
- **Miembro:** Genera contenido localmente usando Antigravity como co-programador y entrega al Sublíder.

**Ciclo semanal:** Lun-Jue trabajan → Vie 4-6 PM revisión de PRs → Sáb-Dom correcciones.
