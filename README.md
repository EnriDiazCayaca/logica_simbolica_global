# Lógica Simbólica Global - Proyecto de Aula 2026

Bienvenidos al repositorio central del proyecto **Lógica Simbólica Global**.
El **Objetivo Único (Norte)** de este proyecto es construir, de manera colaborativa, una plataforma web completa e interactiva para que cualquier persona en el mundo aprenda y aplique Lógica Simbólica.

---

## 🚀 La Métrica de Éxito
Lograr que el 100% de los temas del sílabo estén implementados funcionalmente antes de nuestra **Fecha Inamovible: 21 de Agosto de 2026**.

## ⚡ Stack Tecnológico
- **Framework Web:** Vue 3 (Single File Components `.vue`) + Vite
- **Enrutamiento:** Vue Router
- **Estilos:** Tailwind CSS v4

---

## 👥 Organización de los Equipos
Cada estudiante es un desarrollador dentro de uno de los 6 Equipos de Dominio. Cada equipo tiene un **Sublíder** responsable de subir los avances al líder del proyecto (Enri).

1. **Fundamentos del Lenguaje** (Ruta: `/src/pages/fundamentos/index.vue`)
2. **Conectivos y Tablas de Verdad** (Ruta: `/src/pages/tablas/index.vue`)
3. **Transformaciones Condicionales** (Ruta: `/src/pages/condicionales/index.vue`)
4. **Inferencias Lógicas Básicas** (Ruta: `/src/pages/inferencias/index.vue`)
5. **Validaciones y Derivaciones** (Ruta: `/src/pages/derivaciones/index.vue`)
6. **Teoría de Conjuntos** (Ruta: `/src/pages/conjuntos/index.vue`)

---

## ⚠️ Reglas de Oro (Permisos)

1. **Prohibido tocar la rama `main` directamente.** Solo el líder de proyecto (Enri) puede aprobar código a la rama principal.
2. Cada equipo solo puede modificar el código dentro de **su propia carpeta** en `src/pages/`. (Ejemplo: Si eres del Equipo 2, solo trabajas en `src/pages/tablas/index.vue`).

---

## 🛠️ Cómo Programar con IA (Flujo Cero-Junior en Vue 3)

Si nunca has programado en Vue 3 o Vite, **no te preocupes**. Utilizaremos Inteligencia Artificial (Cursor / Antigravity / Google AI) para que nos asista. 

### Pasos a seguir:
1. **Clona** este repositorio en tu computadora.
2. Instala las dependencias: `npm install`.
3. Inicia el servidor de desarrollo: `npm run dev`.
4. Crea una rama para tu equipo: `git checkout -b equipo-X-tu-tema`.
5. Abre el proyecto en tu editor.
6. Pídele a la IA: *"Soy principiante. Ayúdame a crear una tarjeta interactiva en Vue 3 sobre Modus Ponens usando Tailwind CSS dentro de mi archivo `src/pages/inferencias/index.vue`."*
7. Una vez que funcione, guarda tus cambios y tu sublíder hará el *Pull Request*.
