Resultados: Se desarrolló un motor lógico completo capaz de analizar, tokenizar, parsear y evaluar fórmulas de lógica proposicional con soporte para cinco conectivos (negación, conjunción, disyunción, implicación y bicondicional) en múltiples notaciones. El módulo genera tablas de verdad con sub-expresiones intermedias y clasifica automáticamente la proposición como tautología, contradicción o contingencia. Se implementaron 25 pruebas unitarias con cobertura del 100% de las rutas de evaluación.

Palabras clave: lógica proposicional, tablas de verdad, análisis sintáctico, árbol de sintaxis abstracta, Vue 3, TypeScript, tautología, contradicción, contingencia.

1. INTRODUCCIÓN
================================================================================
La lógica proposicional constituye la base formal del razonamiento matemático y computacional. Las tablas de verdad, herramienta fundamental de este campo, permiten determinar el valor de verdad de una fórmula compleja para cada posible combinación de valores de sus variables proposicionales. A pesar de su importancia pedagógica, no existen plataformas web de código abierto, en español y orientadas a estudiantes universitarios de habla hispana, que implementen este proceso de forma interactiva con trazabilidad completa de sub-expresiones.

El presente informe documenta el trabajo del Equipo Sinergia, responsable del módulo Tablas de Verdad dentro del proyecto colaborativo LogiLearn, desarrollado por el aula del curso Lógica Simbólica (MATG1001, Semestre 2026-I) de la Universidad Nacional Pedro Ruiz Gallo. El módulo implementa un motor lógico de propósito general, capaz de procesar entradas en múltiples notaciones, construir un árbol de sintaxis abstracta (AST), evaluar la fórmula y clasificarla semánticamente.

La documentación sigue el formato de artículo técnico compatible con SciELO y está organizada en las siguientes secciones: (2) Marco Teórico, (3) Arquitectura del Sistema, (4) Explicación Microscópica del Código, (5) Manual de Usuario, (6) Evolución por Sprints, (7) Pruebas y Validación, y (8) Conclusiones.

2. MARCO TEÓRICO
================================================================================
2.1 Lógica Proposicional y Conectivos Lógicos:
- Negación (¬ / NOT): operador unario que invierte el valor de verdad. ¬V = F; ¬F = V.
- Conjunción (∧ / AND): verdadera si y solo si ambos operandos son verdaderos.
- Disyunción (∨ / OR): verdadera si al menos uno de los operandos es verdadero.
- Implicación (→ / IMPLIES): falsa únicamente cuando el antecedente es V y el consecuente es F. Equivale a ¬P ∨ Q.
- Bicondicional (↔ / IFF): verdadera cuando ambos operandos tienen el mismo valor de verdad.

2.2 Clasificación Semántica de Proposiciones:
- Tautología: fórmula cuya columna de resultado contiene únicamente valores V (ej. P ∨ ¬P).
- Contradicción: fórmula cuya columna de resultado contiene únicamente valores F (ej. P ∧ ¬P).
- Contingencia: fórmula que contiene al menos un V y un F en su columna de resultado (ej. P ∧ Q).

2.3 Árbol de Sintaxis Abstracta (AST) y Precedencia:
La precedencia adoptada en el motor, de mayor a menor prioridad, es:
¬ > ∧ > ∨ > → > ↔
Esta jerarquía garantiza que P ∧ Q → R se interprete formalmente como (P ∧ Q) → R y no como P ∧ (Q → R).

2.4 Gramática BNF:
Expresion     ::= Bicondicional
Bicondicional ::= Implicacion ( '<->' Implicacion )*
Implicacion   ::= Disyuncion  ( '->'  Disyuncion )*
Disyuncion    ::= Conjuncion  ( 'v'   Conjuncion )*
Conjuncion    ::= Negacion    ( '^'   Negacion )*
Negacion      ::= '~' Negacion | Primario
Primario      ::= VAR | '(' Expresion ')'

4. EXPLICACIÓN MICROSCÓPICA DEL CÓDIGO
================================================================================
4.1 Motor Lógico (src/lib/truth-table/evaluator.ts):
- Tipos e Interfaces: 'VAR' | 'NOT' | 'AND' | 'OR' | 'IMPLIES' | 'IFF' modelan el AST binario/unario recursivo.
- ErrorParseoLogico: Clase de error personalizada extendiendo Error.
- Normalización: Expresiones regulares para unificar 15+ notaciones (Unicode, ASCII, palabras en inglés como AND, OR, NOT).
- Tokenizador: AFD simple en O(n) que genera lista de Tokens discretos.
- Clase Parser: Análisis descendente recursivo con peek (mirar) y consume (consumir).
- Generador de Filas con Aritmética de Bits:
  Para n variables, el bucle itera i de 0 a 2^n - 1. Para la variable idx, extrae el bit (n - idx - 1) mediante:
  (i >> (n - idx - 1)) & 1 === 0  --> Asigna V si es 0, F si es 1.
  Garantiza el orden canónico universal (V,V,V / V,V,F / ... / F,F,F).
- Evaluación Recursiva: Semántica de Tarski con !evaluar(izquierdo) || evaluar(derecho) para la implicación.
- Clasificación: Conteo de verdaderas y falsas en la matriz principal.

4.2 Vista Principal (src/pages/tablas/index.vue):
- Estado reactivo con ref y reactive para variablesActivas.
- Watcher reactivo que detecta variables en tiempo real mientras el usuario escribe.
- Computed properties para el texto descriptivo y la explicación paso a paso.

5. MANUAL DE USUARIO — GUÍA PASO A PASO
================================================================================
5.1 Acceso:
Navegar a la ruta /tablas en la barra de navegación superior.

5.2 Sintaxis Permitida:
- Negación: !p, ~p, ¬p, NOT p
- Conjunción: p & q, p ^ q, p ∧ q, p AND q
- Disyunción: p | q, p v q, p ∨ q, p OR q
- Implicación: p -> q, p => q, p → q, p IMPLIES q
- Bicondicional: p <-> q, p <=> q, p ↔ q, p IFF q

5.3 Generación y Lectura:
- Presionar «Generar tabla» o pulsar Enter.
- Revisar columnas de variables, columnas intermedias de subexpresiones y columna de resultado.
- Ver clasificación en el panel lateral: TAUTOLOGÍA (todo V), CONTRADICCIÓN (todo F), CONTINGENCIA (V y F).
- Usar ToggleSwitch para activar/desactivar variables fijándolas en Verdadero.
- Clic en «¿Cómo se resolvió?» para ver la explicación paso a paso.
