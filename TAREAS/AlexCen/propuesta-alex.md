### 1. Problema a Resolver
A los alumnos que llevan el curso de Logica Simbolica se les dificulta demostrar las conclusiones de razonamientos (validos / invalidos) haciendo uso de las inferencias logicas validas.

### 2. Funcionalidad Propuesta
Elaboración de una interfaz para la aplicación de inferencias logicas validas para la resolución de problemas.
Se escribira por pantalla las premisas en formato texto, para posteriormente cambiarlo por simbolos logicos

Ej:
p entonces q  = p -> q
no(p) o q = ~p V q
p o no(q) = p V ~q
